# Security policy

Please report vulnerabilities privately to **frolicmap.official@gmail.com**
rather than in a public issue. This is a best-effort, volunteer project, so
there is no response-time commitment. In scope: the Cloudflare Worker (`worker/`)
and the web app (SPA) in this repository. frolicmap has no user accounts and
stores no personal data beyond hashed-IP counters used for abuse limiting.
